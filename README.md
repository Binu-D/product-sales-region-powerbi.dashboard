Product Sales Region Analysis

Project Overview
This project analyzes product sales across different regions using Microsoft Power BI.

Tools Used
* Microsoft Excel
* Power BI

 Project Objectives
* Analyze total sales by region and product.
* Identify sales trends and customer behavior.
* Create an interactive dashboard.
* Generate useful business insights.

 Data Cleaning
The dataset was cleaned and transformed using Excel and Power Query before creating the Power BI dashboard.

 Dashboard
The dashboard includes sales analysis, regional performance, product performance, and other key business metrics.

Key Insights
Insights from the dashboard will be added after completing the analysis.
